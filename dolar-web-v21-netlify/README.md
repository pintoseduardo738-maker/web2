DÓLAR WEB — v9

Acceso de proyecto: cualquier dirección @gmail.com con la contraseña configurada para la demo.
Incluye cotizaciones, conversión, ahorro, inversiones con fracciones/microacciones, Bitcoin, tarjetas, recibir/enviar dinero, transferencias locales e internacionales, historial persistente, configuración, soporte IA y editor visual.

Regalías configuradas: 3% en conversiones y 4% en transacciones externas. Se pueden ajustar desde el editor externo.

Para Google Sites: usar la carpeta google-sites como Web App de Apps Script y luego insertarla en Google Sites como página completa.
