# Editor visual de Dólar Web

## Abrirlo en Netlify
Después de publicar el contenido de esta carpeta, abrí la URL del sitio y agregá `/editor.html` al final. Ejemplo: `https://tu-sitio.netlify.app/editor.html`.

## Mover objetos
1. Dejá activado **Modo diseñador**.
2. Hacé clic sobre el texto, botón, icono o tarjeta que quieras modificar.
3. Sin soltar, arrastrá el elemento a su nueva posición.
4. Usá el panel de la izquierda para cambiar contenido, color, tamaño, fondo, bordes y espaciado.
5. Pulsá **Guardar todo** al terminar.

El editor guarda los cambios en el almacenamiento local del navegador. Eso sirve para editar y probar desde ese navegador. En un sitio estático de Netlify, esos cambios no se publican automáticamente para todos los visitantes; para hacerlos globales hay que incorporar los cambios a los archivos y volver a desplegar el sitio, o conectar el proyecto a un backend/CMS.
